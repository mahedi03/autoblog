## 1. CORE PRINCIPLE

Google's Helpful Content System is designed to ensure search results include **content created for people, not for search engines**. SEOForge produces content that is both SEO-optimized AND genuinely helpful.

> The key question: "Would a real expert create this content to help people, or does it exist only because someone wanted to rank for a keyword?"

## 2. PEOPLE-FIRST CONTENT CHECKLIST

Every article MUST pass ALL of these checks:

### Does the content provide substantial value?

```
CHECK: Would someone reading this article learn something they couldn't easily
find by reading the first Google result?

HOW TO PASS:
- Include at least 3 unique insights not found in competitor content
- Add original examples, case studies, or analysis
- Provide actionable steps (not just theory)
- Include expert tips from real experience
- Cover angles that competitors miss (from content gap analysis)

RED FLAGS:
✗ Content is a rewrite of what already ranks
✗ Content only adds more words, not more value
✗ Content provides generic advice available everywhere
```

### Does it demonstrate first-hand expertise?

```
CHECK: Could only someone with real experience have written this?

HOW TO PASS:
- Include "what actually works" insights
- Reference specific tools, methods, or processes by name
- Share common mistakes that only practitioners would know
- Include nuanced advice (when X, do Y; but when Z, do W)
- Show awareness of edge cases and exceptions

RED FLAGS:
✗ Content reads like a textbook summary
✗ No practical advice beyond basic theory
✗ Could have been written by reading Wikipedia
```

### Does it have a primary purpose or focus?

```
CHECK: Does the article have a clear, specific focus aligned with search intent?

HOW TO PASS:
- Target a specific keyword with clear intent
- Stay focused on the topic (no tangential sections)
- Every section should serve the main topic
- Clear structure that guides the reader toward their goal

RED FLAGS:
✗ Article tries to cover too many topics
✗ Sections included just for word count
✗ Topic drifts from the main keyword/intent
```

### Will readers feel they've learned enough?

```
CHECK: After reading, can the reader achieve their goal without searching again?

HOW TO PASS:
- Cover the topic comprehensively (address all major subtopics)
- Answer follow-up questions proactively (FAQ section)
- Include step-by-step instructions where applicable
- Provide specific recommendations (not just "it depends")
- Address common objections and concerns

RED FLAGS:
✗ Content ends abruptly without resolution
✗ Key questions left unanswered
✗ Reader would need to search elsewhere for practical details
✗ Vague advice ("choose the best option for your needs")
```

### Will readers have a satisfying experience?

```
CHECK: Is the content pleasant to read and easy to consume?

HOW TO PASS:
- Clean formatting with proper headings, lists, tables
- Short paragraphs (max 3 sentences)
- Visual variety (text + lists + tables + images)
- Logical flow from section to section
- Professional quality (no errors, no fluff)
- Mobile-friendly layout

RED FLAGS:
✗ Wall of text with no formatting
✗ Excessive ads or CTAs that interrupt reading
✗ Poor grammar or spelling
✗ Inconsistent formatting
✗ Content is padded with filler
```

## 3. CONTENT RED FLAGS TO AVOID

### Patterns That Trigger Negative Signals

| Pattern | Why It's Bad | How to Avoid |
|---------|-------------|-------------|
| Content on many unrelated topics | Signals "publish everything" strategy | Stay within your topical authority |
| Extensive automation without value | AI-generated slop | Every sentence must add genuine value |
| Summarizing without adding value | No original contribution | Add unique analysis, examples, insights |
| Writing about trending topics without expertise | Chasing traffic without knowledge | Only cover topics within your expertise |
| Content that makes users search again | Failed to satisfy intent | Cover the topic completely |
| Writing to a word count | Padding with filler | Write until the topic is covered, then stop |
| Using AI to produce at scale without quality | Quantity over quality | Quality gates, human review |
| Clickbait titles that don't deliver | Broken trust | Title must match content accurately |

## 4. HELPFUL CONTENT SCORING

### Scoring Criteria (per SYSTEM.md Section 8.4)

| Criterion | Points | How to Score |
|-----------|--------|--------------|
| **Unique Value** | 20 | Count unique insights beyond competitors |
| **Intent Satisfaction** | 20 | Does content fully answer the search query? |
| **Expertise Demonstration** | 20 | Practical tips, correct terminology, depth |
| **Actionability** | 20 | Can reader take specific actions after reading? |
| **Reading Experience** | 20 | Formatting, flow, visual variety |
| **Total** | **100** | **Minimum pass: 75** |

### Detailed Scoring Rubric

**Unique Value (20 points):**
- 20: 5+ unique insights, original analysis, exclusive data
- 15: 3-4 unique insights, good examples
- 10: 1-2 unique insights, mostly covers same ground as competitors
- 5: Minor variations on competitor content
- 0: Essentially a rewrite of existing content

**Intent Satisfaction (20 points):**
- 20: Completely answers the query, no follow-up search needed
- 15: Mostly answers, minor gaps
- 10: Partially answers, reader may search for more
- 5: Barely addresses the query
- 0: Doesn't match intent at all

**Expertise Demonstration (20 points):**
- 20: Deep expertise obvious, practical wisdom, nuanced views
- 15: Good knowledge demonstrated, some practical advice
- 10: Surface-level knowledge, basic advice
- 5: Generic content, could be written by anyone
- 0: Factual errors or misleading information

**Actionability (20 points):**
- 20: Clear steps, specific recommendations, tools named
- 15: Good advice, mostly specific
- 10: Some actionable content, some vague
- 5: Mostly theoretical, few practical takeaways
- 0: No actionable information

**Reading Experience (20 points):**
- 20: Excellent formatting, visual variety, engaging flow
- 15: Good formatting, easy to read
- 10: Adequate formatting, somewhat monotonous
- 5: Poor formatting, hard to scan
- 0: Wall of text, no structure

## 5. CONTENT QUALITY PRINCIPLES

### The Value-First Framework

```
Before writing any section, ask:
1. What unique value does this section add?
2. Would an expert include this section?
3. Does this help the reader achieve their goal?
4. Is this the best way to present this information?

If the answer to any question is "no," revise or remove the section.
```

### The "Would a Real Expert Write This?" Test

```
For every paragraph, imagine a recognized expert in the field reading it.
Would they:
- Agree with the accuracy?
- Find the advice useful?
- Consider the depth appropriate?
- See it as worthy of publication under their name?

If any answer is "no," revise until all are "yes."
```
